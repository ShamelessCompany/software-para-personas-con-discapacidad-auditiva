# Licencias de terceros

## Código

Las dependencias JavaScript y Python conservan sus licencias originales. Revise los archivos de licencia instalados por npm y pip antes de redistribuir binarios.

## Vosk

Vosk API y `vosk-model-small-es-0.42` se distribuyen bajo Apache License 2.0 según el catálogo oficial de modelos. El modelo no se incluye en este repositorio. `npm run model:download` lo obtiene desde `https://alphacephei.com/vosk/models/` y muestra el SHA-256 observado.

Al crear un instalador que incluya Vosk o su modelo, adjunte el texto y los avisos requeridos por Apache 2.0.

## Material LSC

Se incluyen 181 videos de fuentes externas: 50 clips LSC50 bajo CC BY 4.0, dos adaptaciones UniValle bajo CC BY-SA 4.0 y 129 originales EXPRESA bajo CC BY-NC-ND 3.0. La licencia MIT del código no cubre estos videos. EXPRESA se conserva sin modificaciones y solo para uso académico/no comercial; no debe incluirse en una oferta comercial por asumir que todo el repositorio es MIT.

Consulte [los avisos de terceros](../THIRD_PARTY_NOTICES.md), [la política de medios](../assets/lsc/README.md) y los manifiestos de [LSC50](../assets/lsc/lsc50/manifest.json), [UniValle](../assets/lsc/univalle/manifest.json) y [EXPRESA](../assets/lsc/expresa/manifest.json) para autoría, procedencia, transformaciones, hashes y restricciones de cada fuente. Una fuente educativa pública no equivale a permiso de redistribución. Cada clip futuro debe tener autorización escrita independiente y metadatos de validación comunitaria.
